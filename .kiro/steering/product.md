# Product Overview

FashionFox is an e-commerce clothing store application built with Next.js. The platform provides:

- Customer-facing storefront for browsing and viewing products
- User authentication with role-based access (Customer/Admin)
- Admin dashboard for managing products and categories using React Admin
- Contact form functionality
- Responsive design with Bootstrap styling

The application supports two user roles:
- **CUSTOMER**: Regular users who can browse products and manage their profile
- **ADMIN**: Administrative users with access to the admin dashboard for content management
